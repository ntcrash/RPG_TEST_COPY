# Magitech RPG dependencies
#
# As of v2.2.5 the pygame -> Arcade migration is COMPLETE. Arcade is the sole
# runtime dependency: it provides rendering, windowing, the game loop, audio
# (arcade.Sound), and input. The Code/gfx.py shim implements the small pygame
# surface/draw/font/mixer/time/sprite/display/event API slice the game uses on
# top of Arcade, so no `import pygame` is needed to run or test the game.
#
# `pygame` is no longer required or installed. The legacy real-pygame drawing
# backend survives only as an explicit, best-effort opt-in
# (MEGITECH_BACKEND=pygame) for developers who install pygame themselves.
